# 00_COMANDO

La parte que no es técnica y que decide si cobras o no.

Casi nadie hace esta carpeta. Es donde se muere la mayoría de los que sí saben
programar: construyen bien y luego no tienen contrato, no facturan, no ponen
límite al alcance, y terminan trabajando gratis para un conocido.

- `estrategia/` — la evaluación, el catálogo, el plan. Reléelos cada mes.
- `finanzas/` — `calculadora-precios.js`, costos reales, ingresos, SAT
- `legal/` — **la más importante de este mes**. Contrato, confidencialidad,
  aviso de privacidad, nivel de servicio, cláusula de datos agregados
- `ventas/` — presentación, propuesta, casos de éxito con números
- `bitacora/` — qué hiciste cada día

> Si este mes solo alcanzas a hacer una carpeta bien, que sea `legal/`.
