# 03_WEBS_Y_RESERVAS

**La web es la puerta, no el negocio.** Margen bajo a propósito: sirve para entrar,
demostrar que cumples, y vender lo recurrente.

- Opción por defecto: **Astro**. Rapidísimo, y el rendimiento ayuda al GEO.
- Next.js solo si hay sesión de usuario, no para un sitio informativo.
- `pagos-mexico/` — investiga comisiones reales de Stripe, Mercado Pago, Conekta y
  Clip antes de recomendar. El cliente te lo va a preguntar.
- `plantillas/` — la segunda web tiene que costarte 20% de la primera.
