## Ritmo diario

```
2 h  ESTUDIO       lo que necesitas para hoy, no "aprender IA en general"
4 h  CONSTRUCCIÓN  sobre el hotel real, con datos reales
1 h  VENTA/ADMIN   contrato, prospecto, factura, bitácora
```

La hora de venta no se salta nunca, ni cuando estés emocionado programando. Es la
que separa un proyecto de un negocio.
